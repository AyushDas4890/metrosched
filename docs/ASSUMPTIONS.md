# Assumptions

## Public facts used (network level)
- KMRL operates a fleet of 25 Alstom Metropolis trainsets on the Aluva–Tripunithura line (~28 km). Source: public KMRL / press material; verify before quoting.
- Real KMRL trainsets are **3-car**; the SIH25081 statement says four-car. The model is car-count agnostic.
- Main depot: Muttom.

## Synthetic / assumed values (NOT real KMRL figures)
| Item | Assumed value |
|---|---|
| Revenue trains required per morning | 18 (25-train fleet) |
| Minimum standby | 2 |
| IBL bay capacity | 6 per depot |
| Cleaning slots per night | 6 (2 crews × 3 slots) |
| Certificate validity windows | RS 30 d, Signalling 60 d, Telecom 90 d |
| Daily km per revenue train | ~350 km |
| Branding contract minimum | 8–14 h/day exposure |
| Cleaning due | every 3 days |
| Depot layout | 3 stabling lines × 9 deep + 6 IBL bays |
| Second depot (scale test) | "Depot-B", synthetic |

All per-train data (certificates, job cards, branding, mileage, bays) is generated by `data/generator.py` with a fixed seed.
